第一次用？我一步步指给你看
点下面的按钮，页面会跳到该点的地方，用绿框圈出来、标上序号，底部跟着一句话告诉你该干什么。大约 1 分钟走完 6 步。
1打开就有填好的例子，不用从零开始
2在「4 正在看的几个候选」里改成你的商品和数字
3点绿色的「生成裁决报告」，右边出结果
常见问题（在哪填物品 / 能加图片吗 / 换设备怎么办）
  • 在哪里填我要对比的物品？往下找到「4 正在看的几个候选」，一个白框 = 一件商品，点「+ 添加一个候选」加更多。
  • 能对比电脑吗？能。最上面的下拉框里就有「笔记本电脑 · 通勤办公」这个现成案例。
  • 能丢张截图让 AI 自动对比吗？能识别，但只识别「名称 + 参数 + 价格」：点「拍照 / 从相册选图」，或在电脑上直接 Ctrl+V 粘贴截图。模型不打分、不排序、不推荐，数字仍要你核对，结论由纯规则算。
  • 填的东西会上传吗？你手填的表单只存在这台设备的浏览器里，刷新自动恢复，不上传。只有你主动选的那张截图会发给看图模型识别，不保存、不建商品库。
  • 换手机怎么办？点「导出备份」存一个 .json，新设备点「导入备份」。
  • 买完以后，能回头看当时判断准不准吗？能。报告下面那张「5 买后回访」记三条：会不会再买、每周真用几次、一句教训。攒几条会自动算出「重来还会买」的比例，并把基本没用的东西点出来；命令行版用 python -m specpick review 得到同一份复盘。
  • 手机上报告在哪？在表单下方，往下划就能看到；回访卡就在报告下面。

0 先选一个例子，或从空白开始

📷 有截图？直接粘进来，我来读

电脑：截图后按 Ctrl+V（Mac ⌘V）粘在本页面任意位置，或把图片拖进来。
手机：点下面的按钮，拍照或从相册选一张。
读完自动填表，你不用申请任何 Key。只读名称和参数，不打分、不排序、不推荐；图片只用于这次识别，不会被存成商品库。
选完大约 10–15 秒出结果，能一次读出整屏商品。

＋ 只有文字？粘文字也能填（备用）

手机相册打开截图 → 长按「提取文字」→ 全选复制 → 粘到下面，一粘就自动填。
这条路不需要联网，识图连不上时用它；名称和价格我来配对，认不出的留空让你核对，不瞎猜。

1 你要买什么

2 你在意哪些方面

每一行是一个比较项。数字项可以打分，文字项只用来做筛选。权重 0 表示「不参与打分，只用来筛选」。

3 必须满足的条件

不满足的候选会被直接淘汰，报告里会逐条写出原因。预算已经自动算一条，这里放别的硬要求。

4 正在看的几个候选

这里就是填你要对比的物品：一个白框 = 一件商品，改名字、价格和各比较项的数字；不够就点下面的「+ 添加一个候选」。只填真正会买的 3–8 个，价格写数字、不用写 ¥。

下面两段可分别保存为 needs.toml 与 items.toml，用命令行跑会得到同样的结果。

裁决报告

填好左边，点「生成裁决报告」就能看到：谁该赢、为什么另一个输了、要改哪个条件才会翻盘。

5 买后回访：过几个月回来记一笔

决策当时写得再清楚，也要用上一阵才知道准不准。买回来之后回来填三件事：会不会再买、每周真用几次、一句教训。
攒够几条，下面会算出「重来还会买」的比例，并把买回来基本没用的东西点出来 —— 下次同类购买，那些权重就该下调。 记录只存在本机，会跟着「导出备份」一起走。
