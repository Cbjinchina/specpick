# DESIGN.md · specpick 课堂演示（5 分钟）

## 全局视觉约定

### ① 画布与安全区

- 1280 × 720，padding 上下 60 / 左右 60，内容区 1160 × 600
- 页脚（仅内容页）：右端 x ≤ 1220，底边 y = 670，字号 14，颜色 muted

### ② 配色（取自产品本身，不用模板色）

| 槽位 | Hex | 用途 |
| --- | --- | --- |
| 主色 | `#176B4D` | 标题、强调块、关键数字 |
| 辅色 | `#E7F3EC` | 卡片底、结论条 |
| 浅辅 | `#86D3AC` | 进度条、分隔强调 |
| 警示 | `#A0471C` | 淘汰、失败、对比中的"它不行" |
| 底色 | `#F5F6F3` | 页面主背景 |
| 正文 | `#1B1E1A` | 主文字 |
| 次要 | `#6C736A` | 注释、说明 |

纪律：主色 ≤60%，辅色 ≤30%，警示色全篇只用于"淘汰/失败"语义，一页 ≤2 处。

### ③ 字体

- 中文：`Microsoft YaHei`（雅黑）；西文：`Arial`
- 阶梯：封面主标 72 / 巨型数字 96 / 章节大字 56 / 页面主标 36 / 卡片小标 24 / 正文 19 / 注释 14
- 全篇只用这一组；数字不单独换字体

### ④ 视觉母题

每页标题左侧一个 10px 圆点（主色），标题下一条贯通内容区的 1px 细线（`#DFE3DB`）。封面/结尾页不用。

### ⑤ 配图清单

无位图。全部用 SVG/几何图形承担叙事（流程链、对比块、数据条），避免 AI 生图与真实数据不符。
